# Dynamatic

Independent design and software studio by [Mahyar Dayani](https://github.com/mahyardyn) and [Tina Ahmadi](https://github.com/TheTina97).

We build developer tools, web interfaces, and standalone software with a strong focus on typography, native browser standards, and performance.

---

### Focus

- **Lightweight by default:** Minimal dependencies, fast load times, and efficient resource usage.
- **Interface craft:** Subtle micro-interactions, spring physics, and solid typographical hierarchy.
- **Native standards:** Prioritizing modern CSS, vanilla web APIs, and full bidirectional (RTL/LTR) support.
